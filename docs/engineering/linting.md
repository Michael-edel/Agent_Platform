# Linting (Ruff) — инкрементальная чистка

## Статус

В проекте включён **Ruff** как обязательная проверка.

Сейчас в кодовой базе есть накопленный “baseline‑долг” по стилю/импортам. Он зафиксирован в файле: `logs/ruff_baseline.txt`.

## Принцип работы (без рефакторинга всего кода)

- `ruff check .` должен быть **зелёным**.
- На первом этапе Ruff проверяет **критичные ошибки корректности** (например, `undefined name` и синтаксис).
- Стиль/импорты и остальной долг чистятся **постепенно** в отдельных PR.

## Как проверяем локально

```bash
ruff check .
python -m pytest -q --tb=short
```

## Правило для новых изменений

Новые файлы и изменения должны проходить Ruff без новых нарушений. Если вы правите legacy‑файл с большим долгом — допускается ограниченная правка, но без ухудшения качества и с сохранением работоспособности.
