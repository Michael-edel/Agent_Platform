# Changelog: Git Hooks - Безопасная версия

## [2.0] - 2025-01-14

### 🔒 Безопасность

#### Pre-commit Hook

**Критические изменения:**
- ❌ **БЛОКИРУЕТ** коммит при обнаружении секретов (было: только предупреждение)
- ❌ **БЛОКИРУЕТ** коммит при обнаружении файлов БД (было: только предупреждение)
- ❌ **БЛОКИРУЕТ** коммит при обнаружении файлов > 1MB (было: только предупреждение)
- ✅ Добавлена проверка синтаксиса Python (блокирует при ошибках)

**Улучшения:**
- Более строгие паттерны для секретов
- Понятные сообщения об ошибках
- Инструкции по исправлению для каждой ошибки
- Поддержка Windows (исправлена проверка синтаксиса Python)

#### Post-commit Hook

**Критические изменения:**
- ✅ Автопуш **НЕ срабатывает** во время rebase/merge/cherry-pick
- ✅ Автопуш можно отключить через `GIT_AUTO_PUSH=0`
- ✅ Автопуш можно отключить через git config
- ✅ Понятные сообщения о статусе (✓/⚠/✗)

**Улучшения:**
- Проверка всех условий перед push
- Понятный вывод причин пропуска push
- Безопасная обработка ошибок (не блокирует коммит)

### 📋 Список проверок

**Pre-commit блокирует:**
1. Файлы с секретами: `.env`, `*.key`, `*.pem`, `secret`, `password`, `token`, etc.
2. Файлы БД: `*.db`, `*.sqlite`, `*.sqlite3`, `*.dump`
3. Большие файлы: > 1MB
4. Синтаксические ошибки Python

**Post-commit пропускает push при:**
1. `GIT_AUTO_PUSH=0` (env переменная)
2. `git-auto-push.enabled = false` (git config)
3. Rebase в процессе
4. Merge в процессе
5. Cherry-pick в процессе

## Миграция с 1.0 на 2.0

### Что изменилось для пользователя:

1. **Pre-commit теперь строже:**
   - Если раньше можно было закоммитить `.env` (с предупреждением), теперь это **блокируется**
   - Нужно убедиться, что все секреты в `.gitignore`

2. **Post-commit безопаснее:**
   - Автопуш не работает во время rebase/merge (безопаснее)
   - Можно отключить через `GIT_AUTO_PUSH=0`

3. **Новая функция:**
   - Проверка синтаксиса Python перед коммитом

### Действия пользователя:

**Ничего не нужно делать!** Hooks обновлены автоматически.

**Если нужно:**
- Отключить автопуш: `GIT_AUTO_PUSH=0 git commit ...`
- Или: `git config --global git-auto-push.enabled false`
