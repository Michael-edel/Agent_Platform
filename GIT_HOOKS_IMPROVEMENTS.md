# ✅ Улучшения Git Hooks

## 🎯 Выполненные улучшения

### 1. ✅ Улучшен вывод размера файлов

**Проблема:** Размер показывался неточно (например, 2,000,000 bytes показывался как "1MB").

**Решение:**
- Точный расчёт размера в MiB с 2 знаками после запятой
- Показывается и байты, и человекочитаемый размер
- Формат: `bytes (X.XX MiB)` или `bytes (X KiB)`

**Пример:**
- `2000000 bytes (1.91 MiB)` (вместо `2000000 bytes (1MB)`)
- `2048000 bytes (1.95 MiB)` (вместо `2048000 bytes (1MB)`)
- `5120 bytes (5 KiB)` (для файлов < 1MB)

**Реализация:**
- Функция `format_file_size()` с точным расчётом дробной части
- Используется в проверках больших файлов и файлов БД

### 2. ✅ Добавлено сканирование содержимого на секреты

**Новая проверка:** Сканирует содержимое staged файлов на секреты.

**Особенности:**
- ✅ Только текстовые файлы (по расширению)
- ✅ Ограничение 200KB на файл (для производительности)
- ✅ Только staged контент (`git diff --cached`)
- ✅ Блокирует коммит при обнаружении секретов

**Паттерны:**
1. **Stripe keys**: `sk_live_*`, `sk_test_*` (24+ символов)
2. **AWS access key**: `AKIA[0-9A-Z]{16}`
3. **Private key blocks**: паттерн `-----BEGIN...PRIVATE...KEY-----` (блокирует RSA/EC ключи)
4. **Generic patterns**: 
   - паттерны `api_key=`, `secret=`, `token=`, `password=` (20+ символов)
   - Требуется минимум 20 символов значения (чтобы избежать false positives)

**Проверяемые расширения:**
`.py`, `.js`, `.ts`, `.json`, `.yaml`, `.yml`, `.xml`, `.html`, `.css`, `.md`, `.txt`, `.sh`, `.bat`, `.ps1`, `.env`, `.conf`, `.config`, `.ini`, `.toml`, `.properties`

**Вывод при обнаружении:**
```
✗ КРИТИЧЕСКАЯ ОШИБКА: Обнаружены секреты в содержимом файлов!

Файлы с секретами в содержимом:
   ● config.py (найден: Stripe key)
   ● settings.json (найден: Generic secret/token/password)
```

## 🧪 Тестирование

### Тест 1: Форматирование размера
```bash
# Создать файл 2,000,000 bytes
dd if=/dev/zero of=large.bin bs=1 count=2000000 2>/dev/null
git add large.bin
git commit -m "Test"
# Ожидается: "2000000 bytes (1.91 MiB)"
```

### Тест 2: Обнаружение секрета в содержимом
```bash
# Создать файл с Stripe key
echo 'STRIPE_KEY="sk_live_..."' > config.py  # Пример (не реальный ключ)
git add config.py
git commit -m "Test"
# Ожидается: Коммит заблокирован, найден "Stripe key"
```

### Тест 3: Ложные срабатывания
```bash
# Создать файл с похожим, но не секретом

git add config.py

# Ожидается: Коммит проходит (не 20+ символов значения)
```
